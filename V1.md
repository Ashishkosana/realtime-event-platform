# V1 design — notification pipeline

Synchronous publish API, Postgres as source of truth, SSE with a cursor, at-least-once webhooks.

Live transport: **SSE** (not WebSocket). Catch-up is the hard part; frames are not.

Fan-out: write-time for explicit recipient lists. All-or-nothing in the publish transaction when `len(recipients) <= FANOUT_CHUNK`.
